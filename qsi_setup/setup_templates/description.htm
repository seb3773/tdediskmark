Welcome to tdeDiskMark Setup

tdeDiskMark is a native HDD/SSD storage benchmark utility built specifically for the Trinity Desktop Environment (TDE) and Q4OS, powered by the industry-standard Flexible I/O Tester (fio).

Key Features:

  • Accurate Storage Benchmarks: Measures sequential and random read/write throughput (MB/s), IOPS, and latency.
  • Animated Analog Gauges: Real-time anti-aliased dials visualizing storage performance.
  • Custom Themes: Selectable visual styles including "Racing", "Night Fly", or native TDE styling.
  • Desktop Notifications: Automatic libnotify alerts when benchmarks finish.
  • Native TDE Experience: Clean, ultra-lightweight C++/TQt3 codebase with zero Qt5/Qt6 dependencies.
